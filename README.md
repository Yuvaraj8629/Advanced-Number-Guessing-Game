
# Advanced Number Guessing Game

A Python game where players try to guess a secret number.

## Features

- Three difficulty levels: Easy, Medium, and Hard
- Limited attempts
- Score system
- Input validation
- Play Again option

## Requirements

- Python 3

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python game.py

## Built With

- Python
- random module
